## Scope And Lenses

Intent: preserve a bounded, reproducible local evaluation attempt, keep exact retention separate from qualified quality review, refuse malformed evidence and prohibit retries or provisioning. One feature batch covers the CLI, helper, focused tests, frozen synthetic corpus and release evidence.

Always-on lenses: correctness, maintainability, testing and project standards. Conditional lenses: security, reliability, adversarial inputs, API contracts and agent accessibility. Performance fan-out was unnecessary because work is bounded to twenty requests and small fixed corpora.

Findings were pooled before gating, deduplicated by file/line and issue, and corroborated across security/adversarial reviewers. All emitted defects had confidence 100 with deterministic reproductions or direct evidence. No weak advisory finding was promoted to a blocker. Independent fixed-state reproductions were run by the security, reliability and adversarial lenses.
