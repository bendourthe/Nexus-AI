## Cost And Risk

The smallest future migration preserves validators while extracting five runnable profiles, separates PR validation from post-merge work, then reconciles aggregates and reporting. It can reduce duplicate execution but changes protection and publication behavior. The maintainer owns QG-v212-1 and any approval for those changes; this bounded evaluation does not silently authorize that migration.

The required integration context is ci-required, read from live develop protection. A successful local suite does not satisfy it. At the comparison checkpoint no branch had been pushed. Subsequent implementation, metadata and main PRs passed their required merge-result checks, and the exact-tag release workflow succeeded; see the [published record](v2.14.1-release.md#published-result).
