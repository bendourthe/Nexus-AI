## CI impact

New tests (`reasoningOpensInPrompt.test.ts`, `golden-run-metrics.test.ts`, `desktop/tests/reasoning-display.test.ts`, the parity assertion) run in the existing root and desktop jobs. The A/B needs both models and a GPU and is local-only. No pipeline file changed and no remote CI ran.

## Limitations

- The VS Code extension and the packaged desktop app were not driven with the LFM model: no shipped entry sets the flag until Phase 4, and the GUI was not driven headlessly. One fixture proves the extension, headless and desktop paths agree.
- The M-3 verdict depends on the owner's reading of the gate text; the alternative literal reading would have declined. Both are recorded in `lfm-ab-results.json`.
