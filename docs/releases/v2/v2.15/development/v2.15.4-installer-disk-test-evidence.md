# Installer disk-test evidence

**Observed**: 2026-10-20, America/Los_Angeles, in `C:/nx-close`.
**Scope**: v2.15.0 BG-2, v2.15.4 task T008. Unit-test isolation only; no product reserve or installer behavior changed.

## Reproduction

The original precision-override test passes with this host's present free space. Force `shutil.disk_usage` to return zero free bytes around the pytest runner, and the same test fails before its mocked HTTP stream runs: `Not enough disk space for demo-video: 0.0 GB free, need ~15.0 GB plus the 10 GB OS reserve`. This reproduces the reported environment dependence without filling or deleting files on the user's drive.

Run from `C:/nx-close/scripts/installer` in PowerShell:

```powershell
$env:QT_QPA_PLATFORM='offscreen'
uv run --quiet --python 3.11 python -c "import shutil,pytest; from collections import namedtuple; Usage=namedtuple('Usage','total used free'); shutil.disk_usage=lambda path:Usage(100*2**30,100*2**30,0); raise SystemExit(pytest.main(['tests/test_hf_weights_puller.py::TestPrecisionVariants::test_state_override_reaches_install_model','-q','--no-cov']))"
```

Observed before repair: one failure at the `assert ok is True` check, with the disk-space diagnostic above.

## Repair and verification

The four mocked-download test classes opt into `ample_download_space`. The fixture provides 100 GiB free, sufficient for their synthetic manifests. `TestDiskPrecheck` still supplies its own insufficient, sufficient and failed-probe results. `TestHfWeightsSmokeIntegration` does not opt into the fixture. Production code was not edited.

Run the full module under the zero-space wrapper:

```powershell

```

Observed after repair: exit 0, 54 passing tests and one skipped live smoke. Run the ample-space wrapper:

From the repository root, `ruff check scripts/installer/tests/test_hf_weights_puller.py --output-format concise`, `ruff format --check scripts/installer/tests/test_hf_weights_puller.py` and `git diff --check` pass. ## Limits

This proves that synthetic download tests are independent of host free space and that explicit reserve-refusal tests still pass. The live Hugging Face download remains skipped. This is not a full installer suite, a physical low-disk installation, a packaged installer observation or a hosted CI result. Those claims require their own evidence.
