## Overview

The seeding comparison answered "should these models be added to Nexus AI Studio?" with no for today, but found one proposal that could discharge a commitment the project has already made. `lfm2.5:2.6b` is pre-ticked as the agentic default in two places: the cpu tier, and the 8 GB matrix's fallback for cards that cannot hold `gemma4:e4b` (6 GB), which `tier_defaults.py` applies to every GPU under 8 GB. Its LFM Open License v1.0 caps free commercial use at USD 10M annual revenue. [model-acceptance.md](../../../../reference/model-acceptance.md) calls that posture "not acceptable for a pre-ticked default when an alternative fits the same tier", and its OQ-6 records that the last replacement attempt (`minicpm5:2b`, v2.4.10) failed because Ollama dropped the model's tool-call delimiters. NVIDIA announced Nemotron 3.5 Bolt E4B (about 4 GB, aimed at on-device agents) for 2026-10-23, under the OpenMDW-1.1 license the catalog already ships for `nemotron-lightning`.

This plan preregisters the gates, then probes E4B in the order the comparison set: official Ollama tag, license text, intact tool calls through Ollama, then memory fit and a golden-task A/B against the holder. The first three gates are model-wide and stop the trial on any non-PASS; fit and A/B are judged per slot, and only passing slots are admitted. The trial reuses the v2.14.0 golden-run tooling (`bin/goldenRunMetrics.mjs`, the 28 tasks in `tests/golden/tasks`) and the shape of its gate record ([gates.md](../../../../archives/v2/v2.14/development/gates.md)), with one runner extension so the CPU arm can run.

The rest of the comparison is bookkeeping: Super VL and DeepSeek V4.1-Flash-1017 get declined-models rows with reopen conditions, the Humanizer resubmission is recorded against its v2.14.1 HOLD, and Bolt 74B-A9B gets a deferred gap because no 24 GB host is available to measure it (the reference host is a 16 GB RTX 3080 Ti Laptop GPU). The DeepSeek Search and Fetch APIs are recorded as a hard no under the MCP Registry Policy. Handwired is not a model proposal; the comparison records it as unchanged from v2.14.1.

## Goals First / Definition of Done

- **Target problem and persona**: the solo builder on a CPU-only machine or a GPU under 6 GB (STRATEGY.md section 2) gets a pre-ticked agentic default whose license limits commercial use, because the project has had no alternative that survives Ollama's tool-call path. Those users have the least hardware freedom to choose another model.
- **Strategy grounding**: serves Approach principle 3 (single-GPU ceiling, tiers adapt to hardware) and metric M2 (every pillar runs within budget on the reference GPU). The Agentic AI Coding pillar ranks first in STRATEGY.md section 4. No new outbound call, account, or service is added; `ollama pull` is the existing user-initiated download path.
- **Gates done**: the E4B gates and their pass rules are committed before any E4B inference. The E-5 wall-clock budget is a recorded parameter set from measured holder speed, outside the frozen rules.
- **Trial done**: the probe record states, per gate and per slot where the gate is per slot, PASS, FAIL, or HOLD with quoted evidence (library page, license text, captured transcripts, parser output, `/api/ps` memory, golden-run metrics). E-1 to E-3 stop the trial on any non-PASS; later gates are then recorded "not run", never inferred.
- **Admission done (per passing slot)**: `catalog.json`, `ModelCatalog.ts`, `models.json`, `recommended.json`, and `model-acceptance.md` change in one commit for exactly the slots that passed; an E4B agentic session completes a golden task in the desktop sidecar (automated) and in the VS Code extension (a recorded manual run by the owner); `lfm2.5:2.6b` is recorded as a removal candidate only if it no longer holds any slot.
- **Decline done (per failing slot)**: a `declined-models.md` row names E4B, each declined slot, the first non-PASS gate, and the reopen condition; no registry file changes for a declined slot.
- **Records done**: `declined-models.md` rows for Super VL, DeepSeek V4.1-Flash-1017, and the Humanizer resubmission; a v2.16 `DF` gap for Bolt 74B-A9B naming the missing 24 GB host.
- **Delivery done**: local gates, independent Goal review, and final integration evidence exist. On admission, `/update release` ships v2.16.0 with an installer rebuild; on a full decline, the records merge to `develop` with no tag and ride the next code release.
