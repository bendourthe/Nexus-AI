## Plan delta

**Disposition**: Incomplete (non-blocking).

**Evidence**: T018 asks for "the explicit caller/run-bound image grant defined in Phase 1" and for exposure through "the actual consuming ToolCatalog/registry seam identified in Phase 1". The control surface has one shared token and no caller identity, Phase 1 named no agent tool seam, and the desktop coding runner enforces no confirmation tiers, so a built-in coding tool would have bypassed the human grant. The plan did not say how a non-UI caller obtains a grant.

**Resolution**: the grant is issued only through the existing Ask inbox approval and bound to caller id, run id and image; agents reach the commands through the authenticated JSON CLI and the bundled `nexus` skill. Recorded as decisions in the image command contract, not as plan text, because the run record binds the plan.

**Consequence for remaining phases**: Phase 7's deep pass should exercise the CLI end to end against a running app if one is available, include the agent flow in the human testing suggestions, and keep WN-1 (packaged flows not automated) open unless that run happens. The Image Studio handbook page needs the saved-image, durable-edit and agent-command behaviour.
