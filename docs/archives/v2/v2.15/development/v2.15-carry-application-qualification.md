## Guarded Application

Application requires the exact manifest hash, pinned validator/native source bytes, explicit owner session and a genuinely verified schema-2 record nonce for this repository/worktree/minor. Its single raw gap-migration class must contain exactly the 245 unique bound and individually named identities, with the expected manifest metadata. Native page codes cover plan/source-ID bindings; the exact manifest hash is separately enforced by this helper and signed in the resulting raw class metadata.

Each carry is planned, dry-run and checked before the public native CLI writes. Existing files use `edit_guard.py --session nexus-ai-archive-readiness`; no guard accept or baseline reset is performed. The resulting source/target bytes, assigned numeric ID, title, preserved body, provenance and open state must match the native plan and manifest. A pending journal with before/expected-after digests precedes each write. Failure or interruption records observed post-write fingerprints and stops without automatic replay or rollback.
