## Contracts

Actual release mapping requires a verified current record, exact frozen plan binding, source pull-request merge ancestry, the published local/remote tag and containment on the release branch. An arbitrary release dictionary does not satisfy it. Existing planned-version checks retain their normal behavior.

Qualified gap identities preserve patch sections. A coarse identity cannot authorize two distinct source items. Historical coarse-copy ratification requires a unique complete source proof and freezes the current source/destination identities, titles and bodies under the existing signed approval structure. Native migrations assign numeric `KIND-N` destination IDs in application order. The unsigned manifest must describe those actual assignments; custom proposal labels are not an allocator feature. Application must verify the manifest hash, exact source coverage, current inputs and destination state before mutation, then prove each resulting copy and its open state.
