# Outline Retirement Evidence

## Outcome

The owner-selected frozen fallback removes experimental `document_outline` and `document_read_section` exposure and their configuration controls. Both tools are absent from the advertised vocabulary and extension/headless registries even when stale outline opt-ins are supplied. The two `coding.documentOutline.*` methods are unknown. Generic OCR, the independent `parse_document` opt-in, active-model document output budgets, native tool history and compaction remain.

The implementation removes catalog/registry/type/activation/guard entries, extension composition, desktop Settings controls and IPC schemas/handlers, contributed extension settings and sidecar flag/summary composition. Desktop, ACP and scheduled hosts now pass `documentContextTokens` for the surviving parser. Generic context resolution and per-call usage parsing live in the existing `outputBudget` module. Truncated parser output recommends `max_pages` and does not recommend either retired tool. The safety SSOT mirror and its canonical generated table remove only the retired permission rows.

Standalone outline algorithms and historical fixture support remain offline-only source. Historical raw measurements, fixtures, prior receipts, user settings and `~/.nexus/outline-cache` data were preserved. No real-use result or answer-quality improvement is asserted, and the frozen futile benchmark was not repeated. Video Lab implementation remains outside this triage scope; its design record retains the owed obligations.
