# Rewrite Evaluation Contract

The JSON contract and its SHA-256 companion freeze four unscored pilot drafts and sixteen held-out drafts. Each language has one edit-needed draft and one clean control per genre. Exact occurrence and structure checks apply only to the decoded rewrite. Factual identity, voice, readability and editing usefulness require separate qualified human judgments.

This is a text-only adaptation of the categorized installed anti-slop guidance, not execution of its full workflow. The contract records distinct source and adaptation hashes. No installed skill body is distributed. The local model is pinned by its full digest and Ollama version. The only request controls are the four declared by LLMOptions; there is no seeded determinism claim.

## Boundaries

The standalone process pins every fetch to the numeric-loopback origin before importing the client, forces redirect rejection and allows only chat and identity/resource probes. This is a process-local fetch restriction, not OS-level egress containment. Pre/post tag observations cannot rule out an unobserved concurrent tag flip or bind a streamed response cryptographically to a model digest.

The host lease refuses competing rewrite evaluations. The append-only request-start ledger persists attempts before dispatch; an interrupted started request consumes its reservation. A mode cannot restart. Existing evidence is never replaced. Source and evidence paths reject symlinks and junctions, with file identity checks before writes. These checks do not provide OS-level protection against every concurrent filesystem rename.

Every request is limited to 120 seconds and 12,000 output characters, including reasoning and change notes. Concurrency is one, with at most twenty attempts and sixty accumulated active minutes. Unknown metrics are null. Ollama resident-byte snapshots are not peak RAM or GPU measurements.

## Observed Pilot

On 2026-10-17, the first pilot request completed in 47,345 ms and returned 338 reported prompt tokens and 1,345 reported completion tokens. The response used a Markdown code fence around JSON, contrary to the frozen envelope. The result is format HOLD; three remaining pilot IDs are explicitly not run. No prompt repair, retry, alternate model or held-out inference is authorized by this failure. Phase 2 records all sixteen held-out IDs as not-run/HOLD.

## Reproduction

Run from the repository root after `npm run build`:

```powershell
node scripts/evaluate-local-rewrites.mjs --contract docs/releases/v2/v2.14/development/v2.14.1-rewrite-contract.json --validate-only
```

Expected: VALID, four pilot items, sixteen held-out items and inference false. Scoring saved JSONL writes to a new output path. Collection modes are single-attempt operations; the committed ledger intentionally prevents replay of this experiment. A new experiment requires separate preregistration and retained ancestry, not deleting its ledger.
