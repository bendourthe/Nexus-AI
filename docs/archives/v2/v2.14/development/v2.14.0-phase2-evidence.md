## CI impact

- New Python tests (`test_audio_streaming.py`, `test_audio_offline.py` additions, `test_audio_stdin_windows.py`) run in the existing `test-python-runtimes` job; the Windows-only stdin test skips on its Linux runner, so CI does not observe that fix. Recorded for Phase 5.
- New Vitest files run through existing globs: `tests/unit/core/audio/AudioRuntimeClient.stream.test.ts`, `tests/unit/core/chat/speakable.test.ts` (root `full`), `desktop/tests/voice-jobs.test.ts`, `desktop/tests/useSpokenReply.test.tsx` (desktop suite).
- The live measurements need weights, a GPU and Ollama; CI does not run them. No pipeline file changed and no remote CI ran.

## Limitations

- The packaged desktop app was not driven: the sidecar's stdio JSON-RPC is the boundary the webview uses, and the timed packaged-app listening check (V-5 on a real speaker, perceived naturalness) is in Phase 5's human testing suggestions.
- V-1 is missed by about 2 s and the PersonaPlex trigger fired; both are recorded in `docs/releases/v2/v2.15/known-gaps.md` (DF-1, DF-2) by owner decision, with the cut-line departure recorded in `voice-latency-results.md`.
