## Plan delta

**Disposition**: False assumption (blocking for T001, resolved inside the phase by owner decision).

**Evidence**: the plan assumed a working desktop voice loop to measure. On the reference host no voice turn could run:

1. The catalog fetched one file per voice model: `kokoro-v1_0.pth` without `config.json` or `voices/af_heart.pt`, and Whisper `model.bin` without `config.json`, `tokenizer.json`, `vocabulary.json` or `preprocessor_config.json`.
2. No Python on the host had `kokoro` or `faster-whisper`; the provisioned media venv did not list them, and a voice-only selection never built that venv.
3. The sidecar never set `NEXUS_AUDIO_PYTHON` or `NEXUS_AUDIO_CWD`, so the audio factory spawned a bare `python`.
4. Kokoro was constructed with no local paths and fetched from Hugging Face on every call.
5. Once provisioned, transcription before any synthesis failed on Windows with "cublas64_12.dll is not found": CTranslate2 loads cuBLAS from `PATH`, and torch's `lib` is not on it.
6. PyAV 19 removed the `metadata_errors` argument that faster-whisper 1.2.1 passes, so even a loadable Whisper failed to decode.

**Owner decision (2026-10-16)**: "Fix provisioning first". The fix landed in this phase under T001 (see Subtasks). The plan file was not edited: its text is hashed into the signed run record.

**Consequence for remaining phases**: Phase 2 builds on a runtime that now loads offline. T005's "construct KPipeline from the local weights_dir" and "HF_HUB_OFFLINE" items are already done here; T005 keeps the cached pipeline and vectorized conversion. Phase 2's packaged-app check needs a reinstall (or re-provision) so the installed runtimes copy picks up the new `engines.py`. Three new gaps (DF-5, WN-6, WN-7) were recorded; because they were created during the run, they cannot migrate at the minor close and must be fixed in this run. Phase 3 is unaffected apart from the T002 inputs below.

**Queue re-assessment (plan entry)**: no other queued plan exists (`check_plan_completion.py members v2.14` lists only v2.14.0; the v2.12 and v2.13 predecessors shipped as v2.12.0 and v2.12.1).
