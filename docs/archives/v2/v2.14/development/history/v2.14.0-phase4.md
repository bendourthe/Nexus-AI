## Plan delta

**Disposition**: Wrong (one T016 field), corrected in the phase; non-blocking.

**Evidence**:

1. T016 says to set `reasoningOpensInPrompt: true` on the admitted entry. T002 measured the opposite: through Ollama this model's template does not open reasoning in the prompt, and its reasoning arrives in the separate `thinking` field. Setting the flag would make every splitter withhold all visible text until a `</think>` that never appears in the content. The flag is therefore not set; the T012 wiring stays as general support.
2. T016 says to "run the catalog generator". No model-catalog generator exists (`scripts/generate-catalog.mjs` builds `docs/index.md`); `catalog.json` round-trips byte for byte through 2-space JSON, so the entry was inserted structurally and the diff is the new entry only.
3. Moving the 16 GB MoE worker job would leave `nemotron-lightning:30b-a3b-offload` with no job, against the job map's "every entry owns at least one job". It keeps a distinct job it actually holds: the 1M-token context window on 16 GB, which the new entry (131K) does not offer.
4. The plan asked for a post-pull digest check "in the existing install path". Two install paths pull Ollama models (the desktop sidecar's `NexusModelRegistry` and the Python installer's router), and both channels must hold the guarantee, so both check.
5. Verifying the check against this host's real pulls found that the shipped `lfm2.5:2.6b` pin (`79fdf003...`, 2026-08-18) no longer matches the upstream file, which Liquid AI replaced on 2026-08-19 (`02a8b7e1...`, matching a fresh pull). Applied to every pinned `hf.co` entry, the new check would have failed and removed that model on reinstall. The check now applies only to entries that also pin a commit (`source.revision`), and the stale value was corrected.

**Consequence for remaining phases**: Phase 5's Goal-vs-codebase review should confirm the model Goal ("an opt-in catalog entry that takes the 16 GB MoE worker job on a frozen win, with integrity-verified weights") against the shipped entry, and note that the "frozen win" rests on the owner's M-3 reading. No new gap.
