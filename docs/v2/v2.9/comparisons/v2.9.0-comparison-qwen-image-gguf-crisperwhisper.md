"Down to 4 GB" matches Q4_0's file size. It does not match the card's own recommended trio, which is about 14.6 GB of files before activations. The license and the ComfyUI-GGUF loader are unchanged from the v2.8.0 report.

### 3.2 CrisperWhisper 2.0 (article)

Page `https://nyra-labs.com/crisperwhisper`, fetched 2026-09-23. Claims, all vendor-reported:

- One model can emit a verbatim transcript (fillers, repetitions, false starts, stutters, laughter) or an intended transcript (clean text, formatted numbers and emails).
- Multilingual, "most of the languages Whisper supports." Version 1.0 was English and German only.
- Disfluency F1 on the vendor's nyra benchmark: CrisperWhisper 2.0 Pro 93.5, CrisperWhisper 2.0 87.8, averaged over 10 languages. English and German are human-labeled. The other eight are synthetic. Pro ranks above the model the page presents as the open system.
- Word-boundary error: 29.6 ms mean on TIMIT, 40.6 ms on Buckeye.
- Long audio uses "conditional continuation" instead of Whisper's 30-second timestamp-token shift.
- "Verbatimize" rewrites a clean transcript into a verbatim one given the audio.
- Inference is CTranslate2, which the page says nyra extended for speculative decoding, word-timing extraction, and hallucination suppression.

Not on the fetched page: a weight repository, a file size, a VRAM figure, a license name, or a statement that the Pro checkpoint is the same weights as the non-Pro model. Those absences are the admission blockers.

## Section 9: Trapdoors

1. A GGUF quantization's file size is not the working set. Q4_0 at 4.15 GB still needs the text encoder.
2. "Open" on this speech page is not a license and not a download. The fetched article never names either.
3. CrisperWhisper 2.0 Pro leads the vendor table. Do not catalog Pro by adopting the non-Pro name.
4. Word timestamps are a gap in `runtimes/audio/engines.py`. Fixing that gap uses the Faster-Whisper segments Nexus already loads. It does not require this model.
