## Overview

The seeding comparison kept one documentation item. The Qwen-Image "4 GB" claim is the same community GGUF already refused in v2.8.0. This plan does not repeat that refusal. CrisperWhisper 2.0 is a vendor page for verbatim versus clean transcripts, vocal-sound tags, and word timings. The page fetched on 2026-09-23 does not publish weights, a license, or a size, and CrisperWhisper 2.0 Pro ranks above the model presented as open.

Phase 1 writes that speech refusal in exactly one home. It edits `docs/reference/model-acceptance.md` only when that file already contains the v2.8.0 exclusion sentences. Otherwise it writes one row in `docs/v2/v2.9/known-gaps.md` and leaves the bar alone. The wait row completes this plan. Copying the sentence into the bar later is the row's suggested next step. No phase edits `catalog.json`, `recommended.json`, `runtimes/audio/engines.py`, or a CTranslate2 fork.

`docs/solutions/` does not exist. `STRATEGY.md` was read. This plan serves the maintainer.
