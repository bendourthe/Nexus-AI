## What landed

- `core/image/GaussianSplat.ts` already decoded local `.splat` and `.ply` bytes and rejected remote URLs. This phase left that module free of DOM, WebGL, and network imports.
- `core/image/index.ts` is the narrow public export for that decoder.
- `desktop/src/modules/image/splatCamera.ts` orbits, zooms, and pans inside a fixed pitch, distance, and pan box. Reduced motion clears inertial spin.
- `desktop/src/modules/image/splatRaster.ts` rasterizes with inline WebGL2 shaders only. Each canvas takes its own context, and a fourth canvas stops at the same cap of 3 used by the metal rings instead of sharing one context. A missing context draws a 2D still.
- `desktop/src/modules/image/SplatViewerCanvas.tsx` mounts that path, shows a typed fallback, retries a lost context, and saves a PNG data URL from the canvas.

## Functional smoke

The plan names jsdom as the phase boundary and forbids a GPU requirement in CI. Mounting `SplatViewerCanvas` is the consumer boundary available here.

- Input: path `https://3daistudio.com/room.splat`. Expected: alert text about a local file, `data-splat-error="remote-url"`, and zero `fetch` or `WebSocket` calls. Observed: that attribute and those spies, 2026-09-22.
- Input: one local Gaussian and `getContext("webgl2")` returning null. Expected: the sentence "WebGL2 is unavailable. Showing a still preview." Observed: that text and `data-splat-fallback="webgl2-missing"`.
- Input: keyboard ArrowRight, repeated "+", and Shift+ArrowRight. Expected: yaw increases, distance stays at or above 0.5, pan stays finite. Observed: those bounds held.
- Input: Save PNG preview with `toDataURL` stubbed. Expected: a `data:image/png` URL and no `fetch`. Observed: the callback received `data:image/png;base64,aaa` and `fetch` was not called.
- Comparison: expected and observed matched on that jsdom boundary. A real WebGL2 framebuffer was not observed.
