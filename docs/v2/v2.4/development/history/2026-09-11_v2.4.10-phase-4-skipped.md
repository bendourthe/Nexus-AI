Decision 2.2 resolved to **option 3**. Sub-task 4.1 carries the same instruction at the top of its prompt: "Skip this entire phase under decision option 3, recording it as skipped with the evidence reference."

The evidence is [v2.4.10-model-evidence.md](../v2.4.10-model-evidence.md), section `## Parser decision`. In short: MiniCPM5-2B emits correct tool calls, but `<function`, `</function>`, `<param`, and `</param>` are tokenizer special tokens (ids 18-21) that Ollama's detokenizer removes before any Nexus parser sees them. All five parsers in `TOOL_FORMAT_NAMES` return zero calls across nine transcripts. Promoting a model to the low-VRAM agentic default when this runtime cannot read its tool calls would route exactly the users the plan was written for to something that does not work for them.
