## Overview

The seeding comparison kept one documentation item and dropped both artifacts. `abenzerps/Qwen-Image-2.1-Uncensored-GGUF` is a community GGUF conversion of official `Qwen/Qwen-Image-2.1`, loaded through ComfyUI and a third-party GGUF node. The card's recommended Q4 file is 4.60 GB and its recommended text encoder is another 9.35 GB. The official license is the Qwen Research License: research and evaluation only. Uncensored photoreal images are already the Image Studio defaults. `bespokelabsai/nimble` is a flat enum and boolean scorer on a 9B LoRA. It cannot emit text or tool-call arguments, the repository has no license file, and it does not close DF-11.

Phase 1 writes that refusal down in exactly one home. It edits `docs/reference/model-acceptance.md` only when that file already contains the v2.7.0 exclusion subsection. A wait row in `docs/v2/v2.7/known-gaps.md` does not unlock a bar edit, and this plan does not append into that sibling file. In every other state, Phase 1 writes one row in `docs/v2/v2.8/known-gaps.md` and leaves the acceptance bar alone. No phase adds a catalog row, an installer default, a diffusers class, a GGUF loader, or a second LLM runtime.

`docs/solutions/` does not exist in this repo, so there is no prior solution entry to reuse. `STRATEGY.md` was read. This plan serves the maintainer, and it says so below.
