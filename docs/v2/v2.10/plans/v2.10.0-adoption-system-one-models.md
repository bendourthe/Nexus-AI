## Overview

The seeding comparison kept one documentation item. Jev is a hosted classifier. Laya is an Apache-2.0 encoder with a Windows install path. Kev is an Apache-2.0 Qwen family from 0.8B to 27B. Nimble was already refused in v2.8.0, and this plan does not write that sentence again.

Phase 1 writes the refusal in exactly one home: `docs/v2/v2.10/known-gaps.md`. It does not edit `docs/reference/model-acceptance.md`, because the v2.8.0 and v2.9.0 plans already own that file. No phase edits `catalog.json`, `recommended.json`, `PromptInjectionScanner`, `ConfirmationGate`, or `commandRouter.ts`.

`docs/solutions/` does not exist. `STRATEGY.md` was read. This plan serves the maintainer.

## Goals First

**Target problem**: A later catalog change can admit a hosted decision API or a second PyTorch runtime because a vendor table says the model is faster than Jev, and the person on one machine then inherits an API key or a classifier that competes for the single GPU. **Persona**: The maintainer (`STRATEGY.md` section 2, secondary). The solo builder is not asked to install Laya, Kev, or a TypeSafe key.

A reader who opens only that bar will not see this refusal until a later plan copies the row, and that delay is accepted. `core/registry/catalog.json` has no id matching jev, laya, kev, nimble, typesafe, or system-one. `tests/unit/docs/v2.4.9-model-acceptance.test.ts` and `tests/unit/docs/v2.10.0-system-one-exclusion.test.ts` pass.

**Key metric**: The maintainer check is that definition of done. This plan does not move STRATEGY M1 through M4, does not claim M5, and does not amend `STRATEGY.md`. It uses the same maintainer-check shape as the v2.9.0 exclusion plan. Whether the 2026-09-23 owner confirmation for that shape also covers this plan is the open grill question. Until that answer, do not edit `STRATEGY.md`.

**Non-goals**: no TypeSafe, OpenRouter, or Modal client; no `laya` package or Hugging Face checkpoint; no Kev weights; no second write-up of the Nimble refusal; no change to the injection scanner, the confirmation gate, or DF-11; no edit to the living acceptance bar in this slot.
