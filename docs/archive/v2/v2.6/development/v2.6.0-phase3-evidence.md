# v2.6.0 Phase 3 evidence: Mermaid behind one sanitiser

**Plan**: `docs/v2/v2.6/plans/v2.6.0-adoption-chat-surface.md`
**Date**: 2026-09-26

## What landed

`desktop/src/shared/security/sanitizeArtifact.ts` owns the HTML `FORBIDDEN_TAGS` list: `style`, `iframe`, `object`, `embed`, `link`, `meta`, `base`. `InteractiveArtifact` imports that function. ESLint `no-restricted-imports` rejects `isomorphic-dompurify` everywhere else. A test walks `desktop/src` and expects exactly two importers: that module and `sanitizeSvg.ts`.

Diagram output uses a separate SVG profile (`USE_PROFILES.svg` and `svgFilters`) that forbids `foreignObject`, `script`, `use`, `animate`, `set`, and `iframe`, then strips anchors and `href`. Mermaid is initialised with `securityLevel: "strict"` and `htmlLabels: false`. `click` lines are removed before render. Label color comes from `.nexus-mermaid` in `desktop/src/styles/globals.css`, because `style` stays forbidden.

Caps, checked before parse: 8192 bytes, 40 nodes, 60 edges. Over the cap, the fence stays a code block with a "Render diagram" button. A render past 1500 ms falls back to the source. Invalid syntax stays in the message with `role="alert"`.

Mermaid `11.12.0` is a direct dependency of `@nexus/desktop` (`desktop/package.json`, locked in the root `package-lock.json`). The component dynamic-imports the package name `mermaid`. It does not name a URL.
