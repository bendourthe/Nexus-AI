# v2.5.1 Phase 3 evidence

## D3

`tauri-driver` has no macOS support, so it is not the driver. The smoke judges a probe report: route-owned selectors, launch exit, timeout, loopback connections, and the SHA-256 of a bundle path. A live Windows Tauri window was not launched in this session. That spike is `QG-v251-2`.

## Checklist classes

From the v2.4.1 operator checklist, this phase automates only class (a): the shell mounts and the four pillar routes expose `chat-page`, `coding-page`, `image-model-select`, and `video-lab-page`. GPU generation, visual taste, and install-machine setup stay manual.

## D4

The parity gate runs in `semantic-release.yml` before `npx semantic-release`, and again as `check-release-assets` in `ci.yml`. It compares `configs/release-artifacts.json` with the installer workflow upload names. Byte size and digest checks run through `checkArtifacts` when a staging directory exists. `release.yml` still publishes after the tag, so it is the audit, not the gate.

The Phase 1 jsdom axe baseline is not used here.

## Verification

`tests/unit/packaged/packaged-smoke.test.ts` passed 7 tests on five consecutive runs (5/5). A missing route selector, a launch failure, a timeout, an `example.com` connection, a missing artifact, and a digest mismatch each produced a named finding.

`node scripts/check-release-assets.mjs` printed `release-assets: PASS parity 3 artifacts`.
