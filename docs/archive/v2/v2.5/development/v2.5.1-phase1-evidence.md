## jsdom rules axe cannot judge

`color-contrast`, visibility, and overlap need a layout engine. jsdom does not provide one. Phase 3 must not reuse `desktop/tests/a11y-baseline.json` against a real webview.

The four pillar routes rendered and axe reported no `(route, rule, selector)` triples in jsdom. The baseline is therefore `[]`. A nameless `<button>` in the same test run reports `button-name`, so an empty baseline is not an unloaded plugin. A new triple fails even when the total count drops (`unexpectedTriples`).
