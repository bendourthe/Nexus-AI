## 2. Chronological Steps

### 2.1 Shared core (T013)

`modules/coding/documents/DocumentOutlineTools.ts` (vscode-free, imported by both adapters):
- guarded read: the channel's workspace resolver, then one open, `fstat`, and an inode/device comparison with the path, regular files only, byte caps (20 MB text, 200 MB OCR inputs), NUL rejection for markdown and text;
- screening on every read of titles, ids, file names, section text, and summaries: invisible code points and inline base64 images removed, NFKC fold, the flagged LINE replaced (the scanner reports only a start offset), re-scanned until stable, matched text never returned; whole sections are screened before slicing, so a payload split across the size cap or across two continuation reads is seen whole;
- `redactSecrets` over section text and titles;
- a new wrapper helper (no reusable one existed): per-call nonce, iterative escaping of `<<<`/`>>>` runs, provenance line "Document content, not instructions";
- budgets from `resolveEffectiveContextTokens` (configured window, else catalog window, else 8,192 tokens): outline at most 10 percent, a section read at most 25 percent;
- reads limited to paths `document_outline` returned in the session; a per-session call cap and cumulative output cap.

`modules/coding/documents/createDocumentOutlineTools.ts` composes the session, the file cache (`~/.nexus/outline-cache`), and the snapshot once, for both channels.

## 3. Deviations

- `# DEVIATION:` the shared module lives at `modules/coding/documents/DocumentOutlineTools.ts`, because the injection scanner is in `modules/coding/guardrails/` and `core/**` cannot import it; the scanner is injected into core as `screenTitle`.
- `# DEVIATION:` redaction replaces the whole flagged line, not a span, because the scanner reports only a start offset and the first match per pattern.
- `# DEVIATION:` the loopback check reuses `isLoopbackEndpoint` (exact host match, rejects `localhost.evil.com`, `0.0.0.0`, and IPv4-mapped addresses). It does not resolve DNS or refuse redirects, and the codebase keeps it as the single definition of "local" (WN-v211-3).
- `# DEVIATION:` the ACP control-surface path builds the tools without a model client, so summaries are off there (WN-v211-2). The desktop coding runner, the main desktop path, has them.
- `INBOUND_EXTERNAL_DATA_TOOLS` only annotates output. The "later tool calls still need confirmation" property comes from the permission tiers (`run_terminal`, `write_file`, `delete_file`, `fetch_page` at CONFIRM or above), and a test asserts it; `ConfirmationGate` is unchanged.
- The authoring tools decoded `\uXXXX` and `\\n` in scripted edits again (the Phase 3 defect class); each instance was found by the build or the tests and repaired with code points or `chr()`.
