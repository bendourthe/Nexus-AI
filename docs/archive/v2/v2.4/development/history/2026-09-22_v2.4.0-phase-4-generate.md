## What landed

- `core/image/SplatGenerate.ts` classifies a host as `ready`, `cuda-missing`, or `unsupported-platform` and rejects a remote or malformed request before any GPU work.
- `core/generations/splatGenerateQueue.ts` enqueues a `splat_generate` child on the existing generation queue, with its own id and output id. Cancelling a queued child and a running child are distinct dispositions. Both end as failed with error `cancelled`.
- `desktop/sidecar/src/image/GaussianSplatRuntime.ts` waits for an injected scheduler, writes a one-row stub splat under the job directory, and deletes that file on timeout, cancel, or an invalid body. The source PNG is compared before and after.
- Image Studio's generate button enqueues only when the host probe is ready. Otherwise it shows the typed reason and does not call the queue. The sidecar pump fails a not-ready job before `GpuScheduler.enqueue`.
